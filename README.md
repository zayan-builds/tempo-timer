# Tempo

A beautiful, private timer for solving the Rubik's cube. Built because no beautiful cube timer existed.

## What makes it different

- Cinematic dark aesthetic. Cormorant Garamond typography. Amber bloom. Nothing like other cube timers.
- On-device history. Your solves never leave your device.
- Optional AES-GCM-256 encryption for your solve history.
- Optional biometric or PIN lock on history.
- Speed comparisons after every solve. Because numbers alone are boring.
- Pro Mode for scrambles, AO5, AO12, and session logs. Off by default.
- Works as a PWA. Install to home screen, no app store needed.
- Open source. MIT licensed.

## Stack

Next.js 14, TypeScript, Tailwind CSS, Framer Motion, Web Crypto API, WebAuthn, IndexedDB, Web Audio API

## Run locally

```
npm install
npm run dev
```
